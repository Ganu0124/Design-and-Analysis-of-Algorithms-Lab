## 🎯 About This Repository

Welcome to the **Design and Analysis of Algorithms Lab**!

This repository contains a collection of Data Structures and Algorithm Design laboratory programs implemented using **C Programming**.

It focuses on understanding algorithmic techniques, solving computational problems, and analyzing algorithm efficiency.

## ✨ Objectives

- 📌 Understand fundamental algorithm design techniques.
- ⚡ Analyze time and space complexity using Big-O notation.
- 💻 Implement algorithms using C programming.
- 🧠 Develop logical and problem-solving skills.
- 📊 Compare algorithm performance and efficiency.
- 🚀 Explore optimization techniques.

## ⚙️ How to Run

**Step 1: Clone the repository**

```bash
git clone https://github.com/Ganu0124/Design-and-Analysis-of-Algorithms-Lab.git
```

**Step 2: Navigate to the repository**

```bash
cd Design-and-Analysis-of-Algorithms-Lab
```

**Step 3: Compile a C program**

```bash
gcc filename.c -o output
```

**Step 4: Execute the program**

```bash
./output
```

For Windows:

```bash
output.exe
```
